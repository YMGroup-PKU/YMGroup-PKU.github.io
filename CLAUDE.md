## Overview

Yaomin Zhao's personal academic website — a Jekyll site based on the **academicpages** template (a fork of Minimal Mistakes). Hosted on GitHub Pages at `https://ymgroup-pku.github.io` from the `YMGroup-PKU/YMGroup-PKU.github.io` repository on branch `main`.

## Local development

- Ruby 3.3.5 via rbenv (system Ruby 2.6 is too old). Activate with `eval "$(rbenv init - zsh)"` before any Ruby command.
- Build: `bundle exec jekyll build`
- Preview: `bundle exec jekyll serve --host 127.0.0.1 --port 4000`
- **Never run `jekyll build` while `jekyll serve` is running** — concurrent writes to `_site/` cause stale state. Kill serve first, then build, then restart serve.

### Gemfile note

The Gemfile uses `github-pages` gem, matching GitHub's build environment. `bundle install` should be run through local proxy (`export https_proxy=http://127.0.0.1:7897`).

### Config live-reload caveat

Changes to `_config.yml`, `_data/navigation.yml`, and collection files (`_publications/`) are **not** hot-reloaded by `jekyll serve`. Kill and restart serve to pick them up.

## Publications management

All 45 papers live as a Python list `PAPERS` in `tools/gen_publications.py`. Each entry is: `(slug, year, category, authors, title, venue, volpart, extra, url)`.

- Categories: `corresponding` (First/Corresponding-Author) and `coauthored` (Co-authored), defined in `_config.yml` → `publication_category`.
- Author's own name marked with `<b>...</b>` tags in the `authors` string.
- Corresponding author marked with `*` suffix.
- The `url` field holds DOI or arXiv link; if empty, no link is rendered.
- `extra` holds strings like `", in press"` or `" (Editor's Pick)"` (appended after volpart in the citation).
- DOI map `DOIS` in the same file is used to fill missing URLs at generation time.
- **To update a paper**: edit the tuple in `PAPERS` or the `DOIS` dict, then run `python3 tools/gen_publications.py`. This regenerates all `_publications/*.md` files.
- **To add a paper**: append a tuple to `PAPERS`, regenerate, and commit.
- The Publications page (`_pages/publications.html`) renders as a flat numbered list grouped by category, with newest = largest number (`<ol reversed>`).

## Key customizations vs upstream academicpages

- Footer: date uses `site.time` for auto-updating "last updated" (fixed from broken `"now"` string in original).
- Sidebar: GitHub icon disabled (empty `github:` in `_config.yml`).
- Navigation: CV link removed; CV PDF file deleted from repo.
- `docs/` and `tools/` excluded from Jekyll build in `_config.yml` (prevents Liquid errors from internal planning docs).
- All content pages use `text-align: justify` via inline `<style>`.
- Unused academicpages sample content (`_posts/`, `_teaching/`, `_talks/`, `_portfolio/`) deleted.
